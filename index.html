複数人・複数端末で同じリストをリアルタイム共同編集できます。無料のFirebaseプロジェクトを1つ用意し、下に設定を貼り付けて共有コードを決めるだけ。同じコードを開いた全員で共有されます。

▸ セットアップ手順（初回のみ・約5分）
  1. Firebaseコンソールで「プロジェクトを追加」
  2. 左メニュー「構築 → Realtime Database」→「データベースを作成」→ ロケーション選択 →「テストモードで開始」
  3. 「プロジェクトの概要」の歯車 → プロジェクト設定 → 「マイアプリ」で </> ウェブ を追加 → 表示される firebaseConfig の { } 内を上の欄に貼り付け
  4. ニックネームと共有コード（合言葉）を入力 →「接続して共有」
  5. 一緒に管理したい人に、この同じページURL・設定・共有コードを共有

※テストモードは初期状態だと誰でも読み書き可。合言葉としての共有コードで軽く保護されますが、本格運用時はRealtime Databaseの「ルール」で制限してください。
